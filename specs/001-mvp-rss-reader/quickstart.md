# Quickstart: MVP RSS Reader

## Prerequisites

- A local .NET development environment
- A browser for running the UI

## Setup

1. Start the backend API.
2. Start the Blazor frontend.
3. Open the frontend in a browser.

## Validation

1. Enter a feed URL in the input field.
2. Submit the form.
3. Confirm that the new subscription appears in the list.
4. Try submitting an empty value and confirm that the app shows a clear validation response.
